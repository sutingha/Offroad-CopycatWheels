# 伪装轮 (Copycat Wheels)

**机械动力：航空学**的附属模组，添加了伪装车轮悬架和模型伪装轮。

[English](README.md)

## 内容

- **伪装车轮悬架** — 一种伪装轻质车轮悬架。
- **伪装车轮悬架II号** — 一种可以卸装两个轮胎的伪装轻质车轮悬架。
- **模型伪装轮** — 一种轮胎，用伪装方块的模型作为轮子。
- **伪装轮调试器** — 可微调旋转、缩放、偏移、碰撞半径与摩擦力。

## 前置需求

- Minecraft 1.21.1
- NeoForge 21.1+
- Create 6.0+
- Create: Aeronautics 1.3+
- Create Offroad
- Create Simulated

## 可选兼容

- **Create: Tracks** - 依托神秘的反射，现在可以兼容tracks的调节器。
